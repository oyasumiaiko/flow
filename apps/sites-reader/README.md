# Flow Cloud Reader

Flow 的 Sites 云端阅读入口。EPUB 与封面存入 R2，结构化书目、进度、批注、
词条和阅读设置存入 D1。所有服务端查询和对象键都以 Sites 转发的稳定 ChatGPT
用户 ID 分区，因此多个获准访问的账号使用同一部署时仍拥有互相独立的书库。

## 数据迁移

书库页面可以直接导入 EPUB，也可以导入原 Flow 的 `flow_backup_*.zip` 备份。
备份导入会保留书籍元数据、阅读位置、进度、批注、词条和单书排版配置。

## 本地验证

安装依赖后运行 `npm test`，它会完成生产构建并检查 D1/R2 绑定和用户隔离契约。
